# Embedded Projects

A curated collection of beginner-to-intermediate embedded systems projects built with **Arduino** and the **AT89C51 (8051)** microcontroller family.

## Overview

This repository contains practical projects focused on digital I/O, timing, LED control, button input, analog sensing, and basic actuator control.  
Each project folder includes its own `README.md` with circuit details, code explanation, and demo references.
